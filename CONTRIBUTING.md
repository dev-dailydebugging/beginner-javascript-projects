# Contributing to Beginner Full-Stack (MERN) Projects

Thank you for your interest in contributing to this repository! Our goal is to provide the most beginner-friendly, clean, and practical full-stack projects on GitHub.

## 📋 Ways You Can Contribute
1. **Add a New Beginner Project:**
   - Must use standard MERN stack or Vanilla JS + Node/Express.
   - Must follow the two-folder structure: `client/` and `server/`.
   - Must include an in-depth `README.md` with walkthrough, API documentation, and extension challenges.
2. **Improve Documentation:**
   - Clarify explanations or add code comments explaining tricky full-stack concepts.
   - Fix typos, broken links, or improve markdown formatting.
3. **Enhance Existing Projects:**
   - Add responsive UI improvements, dark mode, or accessibility attributes (`aria-` tags).
   - Add input validation or error-handling improvements.

## 🛠️ Step-by-Step Contribution Workflow

1. **Fork the Repository:**
   Click the "Fork" button on the top right of the repo page.

2. **Clone your fork locally:**
   ```bash
   git clone https://github.com/<your-username>/beginner-javascript-projects.git
   cd beginner-javascript-projects
   ```

3. **Create a descriptive feature branch:**
   ```bash
   git checkout -b feature/add-weather-dashboard
   ```

4. **Make your changes:**
   - Test both the backend (`npm run dev`) and frontend (`npm run dev`) thoroughly.
   - Ensure clean code formatting and no console errors.

5. **Commit your changes:**
   ```bash
   git commit -m "feat(projects): add 06-weather-dashboard with express proxy"
   ```

6. **Push to GitHub & Submit a PR:**
   ```bash
   git push origin feature/add-weather-dashboard
   ```
   Open a Pull Request on GitHub with a clear description and screenshots/GIFs of your project in action!
